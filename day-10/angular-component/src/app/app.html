About this Component

This is a standalone Angular reusable component that calls the same Express.js REST API as the main React application.

  • Accepts facilityId and selectedDate inputs
  • Calls GET /api/facilities/:id/availability?date=YYYY-MM-DD
  • Displays loading, error, empty, and populated states
  • Can be embedded in any Angular application
